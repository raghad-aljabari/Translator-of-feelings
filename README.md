## المشكلة

يعاني كثير من أطفال التوحد ومن يعانون من صعوبات في النطق من عجز كامل في التعبير عما يشعرون به. هذا الصمت القسري يخلق فجوة عميقة داخل الأسرة — الأهل لا يعرفون هل طفلهم في ألم، في توتر، أم في حالة جيدة. ومع تراكم هذا الغموض يومياً، تتصاعد نوبات التوتر وتتراجع جودة الحياة للجميع.

<br/>

## الحل

**مترجم الأحاسيس** نظام ذكاء اصطناعي مدمج يعمل كمساعد شخصي صامت. يرصد تعبيرات وجه الطفل بشكل مستمر، يحللها فورياً، ويرسل للأهل إشعاراً واضحاً بالحالة الشعورية — كل ذلك دون أي تدخل أو إزعاج للطفل.

## كيف يعمل النظام

**المرحلة الأولى — الالتقاط**
كاميرا HuskyLens المدمجة بالذكاء الاصطناعي تراقب وجه الطفل بشكل مستمر. صُممت لتعمل في الخلفية دون أن يلاحظها الطفل أو يتأثر بها.

**المرحلة الثانية — التحليل**
خوارزمية مكتوبة بـ MicroPython تستقبل بيانات الكاميرا وتحلل الفروق الدقيقة في ملامح الوجه — حركة العينين، زوايا الفم، توتر العضلات — وتصنف الحالة العاطفية فورياً.

**المرحلة الثالثة — المعالجة**
وحدة LEGO SPIKE Prime تستقبل نتيجة التحليل وتعالجها، ثم توجّه الإشارة إلى واجهة الأهل عبر النظام المتكامل.

**المرحلة الرابعة — الإشعار**
يصل الأهل إشعاراً فورياً يعرض الحالة الشعورية لطفلهم بطريقة مرئية وبسيطة — سعادة أو توتر أو ألم.

## تشغيل المشروع

**المتطلبات**

- LEGO SPIKE Prime
- HuskyLens مع توصيل I2C أو UART
- MicroPython مثبّت على الوحدة

**خطوات التشغيل**

```
1. وصّل HuskyLens بوحدة SPIKE Prime عبر المنفذ المخصص
2. ارفع ملف main.py على الوحدة
3. شغّل البرنامج من واجهة SPIKE Prime
4. النظام يبدأ التحليل والإشعار تلقائياً
```

**الكود الأساسي**

```python
from face_analyzer import EmotionDetector
from notifier import ParentNotifier

detector = EmotionDetector()
notifier = ParentNotifier()

while True:
    emotion = detector.analyze()   # تحليل تعبير الوجه
    notifier.send(emotion)         # إرسال الإشعار للأهل
```
