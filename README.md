## 🧠 نبذة عن المشروع

> **"مترجم الأحاسيس"** هو مشروع تقني مبتكر يهدف إلى دعم التواصل الإنساني، خاصةً لدى أطفال التوحد ومن يعانون من صعوبات في النطق.

يُعاني كثير من هؤلاء الأطفال من **صعوبة بالغة في التعبير عن مشاعرهم**، مما يُشكّل تحدياً يومياً ضخماً للأسرة بأكملها. هنا يأتي دور مترجم الأحاسيس — نظام ذكي يعمل بصمت في الخلفية، يُحلّل تعبيرات الوجه ويُرسل تقارير فورية للأهل بلغة بسيطة ومفهومة.

<br/>

## 🚀 تشغيل المشروع

```python
# ١. توصيل HuskyLens بـ LEGO SPIKE Prime
# ٢. رفع الكود على الوحدة

from face_analyzer import EmotionDetector
from notifier import ParentNotifier

detector = EmotionDetector()
notifier = ParentNotifier()

while True:
    emotion = detector.analyze()       # تحليل التعبير
    notifier.send(emotion)             # إرسال الإشعار
```
